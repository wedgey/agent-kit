# The orchestrator watches for stalled lanes

A lane reports by ending its turn, and the orchestrator wakes only on those reports. A lane whose model stream stalls never ends its turn, so it sends nothing. Claude Code's own stall notice does exist, but on 2026-10-29 we found four of them in our transcripts that reached an idle orchestrator 114, 169, 268 and 447 minutes after the lane's last entry, each when the session woke for some other reason. The epic playbook already had a "Silent too long" rule, but the orchestrator is asleep while it waits, so a rule it must remember has nothing to make it fire.

A hook cannot fire either, because hooks run on tool events and an idle session makes none. So the orchestrator starts `tools/watch-lanes.mjs` in the background for each lane, the same way a lane watches its own PR (ADR 0012). It looks at the lane transcript once a minute and, once the file has stayed unchanged for 15 minutes of its own looks, reads the last entry. It exits when the lane owes a reply to a tool result or message, or is still in a tool call. Its completion notice wakes the orchestrator at no model cost while it waits. A lane that ended its turn is idle by design, waiting on its own watcher or background work, and never counts. The stalled lane of 2026-10-29 owed a reply to a tool result, so this would have found it about 15 minutes in.

Quiet time runs on the watch's own looks, not the file's age, because on 2026-10-20 and 21 every lane on the box went quiet in the same minute for 44 to 147 minutes while the machine paused. A watch that measured file age would report every lane at once when the machine woke, and a second report would replace a healthy lane. A gap of more than three intervals between looks restarts every count. One transcript entry can reach megabytes, so the read widens until an entry with a message fits. An entry of thinking alone never ends a turn, so it counts as mid-turn. A stall right after a text entry still reads as an ended turn, because the transcript does not mark a finished turn apart from a cut-off one. That gap stays open.

The orchestrator then reads the lane's state from git, not its transcript, and continues the lane, which resumes it with its context. A second stall in the same stage replaces the lane from its pushed branch. A lane still inside a tool call counts only after 45 minutes, because four healthy lanes sat in foreground calls for 18 to 22 minutes and then carried on. A lane that handed its report back through a handback tool, or that the operator interrupted, ends on a user entry but is idle, so both count as ended turns. A watch lasts 72 hours, because each restart costs the orchestrator a turn and lanes wait days to merge. The script reads the transcript file itself, which the binding otherwise keeps out of the orchestrator's context. Its output is one JSON line.
