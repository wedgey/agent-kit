# The orchestrator hands over, and lanes land their own PRs

ADR 0011 gave lanes a context limit and left the session's own agent to the operator. On 2026-10-28 and 29 we measured one epic's orchestrator over two days. It made 361 model calls with a median context of 325k tokens and a largest of 966k, and those calls re-read about 250M tokens. It had been resumed and compacted twice rather than restarted. Text-only calls, mostly status updates written after a lane notice, used 28% of that. Calls that ran a shell command itself used about 25%: rebases, pushes, lint, typecheck, unit and end-to-end tests, and deploy checks while it shipped each PR. Every notice cost a call at that context size, whatever the notice said.

So three things change. The context hook now speaks to the session's own agent too, at `CONDUCTOR_SESSION_CONTEXT_LIMIT` (default 150k), lower than a lane's because the orchestrator lives for the whole epic. The epic playbook gains a handover: every working lane pushes and reports Context full, the orchestrator writes the epic's state and those reports to the epic's issue, stops the lanes, and asks the operator for a fresh session that re-dispatches them. Lanes land their own PRs when the operator asked to land, through a LAND line in the brief, so the checks and merges run in a lane's small context and the orchestrator runs none. And a notice that needs nothing from the operator gets no reply text.

The operator's request to land is still the only thing that lets a PR merge. LAND carries it to the lane quoted, and a lane without it never merges. A lane under LAND still waits for the orchestrator's go after its Merge-ready report, so the orchestrator's read of the verdicts and the diff still comes before the merge. That costs one call per PR, which the notice cost anyway. When tickets land as they pass, the epic's own verifier runs on trunk after the last merge and can no longer stop one, so its failure becomes a new ticket. A handover re-dispatches every working lane, which costs each one a fresh start from its report. A subagent lane ends with its session in Claude Code, so there is no cheaper way to move an epic to a fresh session. Whether 150k is the right session limit is not measured yet.
