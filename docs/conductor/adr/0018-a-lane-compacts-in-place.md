# A lane compacts in place

ADR 0011 had a lane hand over at its context limit: it pushed, wrote a Context full report, and the orchestrator stopped it and dispatched a fresh lane from that report. Each handover cost a stop, a new dispatch, a fresh lane re-reading its reading list and the code, and an orchestrator turn to relay the report, and it lost whatever the report left out. The orchestrator itself had already stopped paying that price: under ADR 0015 it compacts its own session with what it must keep and a prompt that resumes it.

So the lane does the same. The Claude Code binding's lane agent sets `autoCompactWindow: 120000`, and Claude Code compacts the lane itself at about 85k to 90k tokens, mid-turn, before the 120k context note of ADR 0017 can come. The plugin's mod hooks `session.compact` for a `conductor:lane` only. It puts a keep ahead of the summarizer's instructions, naming the lane's whole brief, its worktree, branch, pushed head and unpushed work, its PR, the step in hand and the next, its decisions with their reasons, what is open, its running delegates, commands and watches by id, and the orchestrator's messages. It adds a resume note after the summary that tells the lane to check `git status`, re-read only what the next step needs, and go on without reporting Context full. The lane keeps its agent id, worktree, watches and message route, so the orchestrator does nothing.

A probe on v2.1.322, 2026-11-11, gave an agent a 100k window. It compacted 8 times in one turn, its turns peaked at 79k, a codeword in the keep survived all 8 summaries, and it finished its task. A second probe the same day ran the plugin's `conductor:lane` from its agent file: it compacted 6 times at 85k to 90k, the resume note followed every summary, and it read all 45 files it was given.

Context full stays for a lane that cannot compact in place: a `general-purpose` lane in the fallback, a separate-session lane, or a harness without the hook. Where Claude Code loads the plugin but not its mod, the lane agent still compacts at its window, since that comes from the agent file, but without the keep or the resume note, so the doctor's Mod check names that loss. A summary can still drop a detail, as a report could, and whether many compactions in one lane cost quality is not measured yet.
