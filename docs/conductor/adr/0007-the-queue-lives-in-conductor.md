# The heavy-check queue lives in conductor

Heavy checks from many lanes and repos compete for the same cores, so the queue and its hooks ship inside the conductor skill, consistent with ADR 0001. The harness's package installs the hook (ADR 0008), so any repo used with conductor gets queued heavy checks and agents that never block a turn waiting. The on-disk protocol is versioned (v1) and state lives box-wide at `$CONDUCTOR_QUEUE_DIR/v1/<queue>/`. A repo may vendor a copy of `queue.mjs` for CI and humans. It must keep the protocol version and layout so every copy on the box queues together. This copy is canonical, and a repo that runs its own hook sets `CONDUCTOR_QUEUE_MANAGED=1` so the two never contradict each other.
