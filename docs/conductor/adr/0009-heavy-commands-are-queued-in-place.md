# Heavy commands are queued in place

The Claude Code package used to deny an unqueued heavy command and name the queued form, so every heavy run cost the agent a refused call and a retry. It now rewrites the command in place, in a mod's `tool.call` hook, into `queue.mjs run --queue=<q> -- bash -c '<command>'`, the same form the agent was told to type. This is safe because a mod's rewrite still passes through the whole permission chain beneath it, as the command it now is, unlike a `PreToolUse` hook's `allow`: a rewrite can never run what the person's rules would refuse. The hook still denies a foreground run on a full queue, so a turn is never parked behind other lanes, and it denies a duplicate of a run that is already queued or running. The module triages the command text itself and starts Node (`tools/hooks/decide.mjs`) only for a heavy or queued command, so a light command costs no process. `queue.mjs` stays the one engine, harness-neutral, with the protocol at v1 (ADR 0007): a moved waiter's new place is its ticket's `createdAt`, the order key every copy already reads.
