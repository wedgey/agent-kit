# Conductor ships as one package per harness

Each harness gets conductor as one package wrapped around the same harness-neutral skill, so installing the package adds every piece and uninstalling it removes every piece. For Claude Code the package is a plugin whose root is this repo's root, so `skills/conductor/` stays the single copy, and the root `skills/` must hold only conductor because any other skill there would ship as `conductor:<name>`. The plugin carries the role agents, the queue's hooks and the always-on pointer, which a session-start hook reads from `setup.md` and adds to the context instead of a line in the operator's instruction file. The plugin sets no `version`, so each install tracks the repo's commits rather than waiting for a version bump. Setup writes nothing any more. It checks the package, runs the doctor and lists what an older install left behind, which amends the install steps in ADR 0006 and ADR 0007, and the skill still needs nothing outside its folder, as ADR 0001 requires.
