# Conductor ships as one package per harness

Each harness gets conductor as one package wrapped around the same harness-neutral skill, so installing the package adds every piece and uninstalling it removes every piece. For Claude Code the package is a plugin whose root is this repo's root, so `skills/conductor/` stays the single copy and the plugin points at it. The plugin carries the role agents, the queue's hooks and the always-on pointer, which a session-start hook adds to the context instead of a line in the operator's instruction file. Setup writes nothing any more. It checks the package, runs the doctor and lists what an older install left behind, which amends the install steps in ADR 0006 and ADR 0007. The skill still names no other skill and needs nothing outside its folder, as ADR 0001 requires.
